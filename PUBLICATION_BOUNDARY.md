# SpiralQIT Public GitHub Boundary

This public repository is the SpiralQIT™ project’s navigation and public-reference layer.

It may contain:

* Project descriptions and public announcements;
* Attribution and provenance summaries;
* Publication-boundary notices;
* Links to authoritative externally hosted releases; and
* Materials expressly marked for unrestricted public repository display.

Restricted Covered Materials are not published in this public repository. Repository presence alone does not place any artifact under the SpiralQIT Restricted Public Use License.

An authoritative restricted release must exist outside public GitHub and identify its exact title, version, date, license, source location, and SHA-256 hash. A GitHub link or summary is not the authoritative copy.
